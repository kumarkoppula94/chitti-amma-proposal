# For My Chitti Amma ❤️

A mobile-friendly romantic proposal page made by Siva.

## Files
- `index.html` — page content and personal message
- `style.css` — romantic theme, layout, and animations
- `script.js` — buttons, playful response, celebration, and a small original synthesized melody

## Preview locally
1. Extract this folder.
2. Open `index.html` in a modern browser.
3. Tap **Play music** to start the gentle synthesized melody. Browsers need a user tap before playing sound.

## Publish free with GitHub Pages
1. Sign in to GitHub.
2. Create a **public** repository named `chitti-amma-proposal` (or another name you prefer).
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` from this folder to the repository root.
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes and refresh the Pages settings page for the published URL.

If your GitHub username is `kumarkoppula94` and the repository is named `chitti-amma-proposal`, the expected URL format is:
`https://kumarkoppula94.github.io/chitti-amma-proposal/`

That URL is only expected after you publish and GitHub Pages finishes deploying; it is not live merely because the files exist locally.

## Personalize it
Edit the message in `index.html`. The music is a simple original melody synthesized in the browser, so no song file is included. If you prefer a specific song, only use audio you have permission to share and add a music player with that audio file or a licensed link.

## Privacy note
A public GitHub Pages website can be viewed by anyone with the URL. Avoid adding private photos, phone numbers, addresses, or other sensitive information unless you're comfortable sharing them publicly.
